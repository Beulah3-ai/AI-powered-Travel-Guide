# AI-Powered Travel Guide

An AI-powered travel guide that generates travel information and audio guides using AI and Murf.AI voice technology.

## Project Links

- **Live Project:** https://ai-powered-travel-guide-frontend-19egdt8vx.vercel.app/
- **Backend API:** https://ai-powered-travel-guide-backend.vercel.app/
- **GitHub Repository:** https://github.com/Beulah3-ai/AI-powered-Travel-Guide

## Technologies Used

- Python and Flask
- Google Gemini API
- Murf.AI
- HTML, CSS, and JavaScript
- Vercel for deployment

## Features

- AI-generated travel descriptions
- Audio travel guides
- Multiple language and voice options
